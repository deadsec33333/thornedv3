# Throned

Static front end mockup of the Throned crypto casino lobby. Plain HTML, CSS and JavaScript, no build step.

## Files

- `index.html` the page
- `style.css` all styles
- `script.js` small animations (coin flip rays, live wins feed, race countdown, claim button)
- `assets/` images

## Hosting

**Vercel:** import this GitHub repo at vercel.com/new. Framework preset: Other. Leave build command and output directory empty.

**GitHub Pages:** repo Settings, Pages, Source: Deploy from a branch, Branch: main, folder: / (root).

Preview only. Nothing is connected to real accounts or payments.
